3. Phím tắt:
- Ctrl + Shift + F: format file
- Ctrl + 1: create static method from function call
- Ctrl + F11: run file
- Ctrl + D: remove line
- Ctrl + Alt + Down(UP)Arrow: duplicate bottom line
- Alt + Down(UP)Arrow: move line up/down
- Ctrl + 3: move editor to any views
- Ctrl + Shift + /: multi comment /* ... */
