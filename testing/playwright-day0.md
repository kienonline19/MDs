- Playwright là một framework mã nguồn mở do Microsoft phát triển, được sử dụng để tự động hóa trình duyệt web và thực hiện kiểm thử tự động (End-to-End/E2E testing)

  #### Các tính năng nổi bật

  1. Hỗ trợ đa trình duyệt: Điều khiển đồng thời các nhân trình duyệt lớn gồm Chromium (Chrome, Edge), Firefox và WebKit (Safari) chỉ thông qua một API thống nhất.
 
  2. Hỗ trợ đa ngôn ngữ lập trình: Cho phép viết mã bằng JavaScript / TypeScript, Python, Java và .NET (C#).
 
  3. Cơ chế tự động chờ (Auto-waiting): Tự động chờ các phần tử (elements) hiển thị hoặc sẵn sàng trước khi thực hiện thao tác, giúp giảm thiểu hiện tượng lỗi do treo/chậm mạng (flaky tests)
 
  4. Ghi thao tác tự động (Codegen): Cung cấp công cụ ghi lại các thao tác chuột và bàn phím trên trình duyệt để tự sinh ra mã kiểm thử ban đầu.
 
  5. Hỗ trợ nâng cao: Mô phỏng thiết bị di động, định vị phần tử linh hoạt (Locator), chụp ảnh màn hình, quay video và kiểm tra mạng (network interception).
 
  6. Tích hợp CI/CD: Dễ dàng đưa vào các hệ thống tự động như GitHub Actions, GitLab CI, Jenkins hoặc Azure DevOps.
